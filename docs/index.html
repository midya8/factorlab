04 / ALL SMALL ORDERS
Same value can cost
a different table.
Enumerate every unobserved-variable permutation, up to 120. A sum-before-max schedule is sufficient for an exact marginal-MAP value. An interleaved schedule can still agree, for example on disconnected factors; agreement on one table is not a universal ordering rule.


05 / LIMITS AND PRIOR WORK
A witness, not
a speed claim.
At most five binary variables, ten nonnegative rational factors and 32 complete assignments. Scope tables are dense. All-sum computes an evidence-restricted partition; all-max computes a joint mode weight. Mixed valid elimination computes the marginal-MAP mass. Arbitrary interleavings give an upper bound, not an attainable assignment or posterior probability. Dividing that bound by evidence mass is still a bound and can exceed one.
Zero evidence mass leaves all probabilities undefined (null), even though nonnegative weight maximizers remain algebraic ties. Inputs are potentials, not necessarily normalized conditional distributions; evidence mass is not itself an evidence probability without the full unconditioned normalizer. Minimum census width is for the evidence-sliced primal graph. Counts exclude rational bit complexity, browser overhead and reference enumeration; no scalability or wall-clock comparison.
Native JSON rejects duplicate keys and limits UTF-8 input to 32KiB. Browser JSON.parse keeps the last duplicate key and limits characters to 32,768. Native index fields reject floating-point tokens; browser JSON turns integer-valued tokens such as 1.0 into 1. Every potential is a bounded integer/fraction string; there is no floating-point inference.
